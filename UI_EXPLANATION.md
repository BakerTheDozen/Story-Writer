# Story Writer UI Guide: Project Management & Backups

This guide explains how to use the new project management features to organize your stories and protect your data.

## 1. Project Management (App Header)
These tools manage your active writing workflow within the browser.

*   **📚 Library**: Your "Project Bookshelf." Open this to see all projects saved in this browser.
    *   **Load**: Switch the workspace to a specific project.
    *   **Delete**: Remove a project from your local library (cannot be undone).
*   **💾 Save**: Snapshots your current characters, chapters, and draft text into the Library. Use this before switching projects or closing the tab.
*   **Create New Project** (Inside Library): Resets the workspace to start a completely fresh story.

## 2. Exports & Hard Backups (Sidebar)
These tools move your data out of the browser and onto your computer for permanent storage.

*   **Download Full Project (CSV)**: Generates a spreadsheet containing your project outline, character list, and chapter summaries. Best for external reading.
*   **Backup Project (JSON)**: The **Safety Net**. Downloads a single file containing *everything*—full prose, settings, and characters. Use this to keep a permanent backup of your work.
*   **Restore from JSON**: Loads a previously saved `.json` backup file. This will rebuild the project and add it to your browser's Library.

## Persistence Summary
| Feature | Location | Persistence Level |
| :--- | :--- | :--- |
| **Library / Save** | Browser | **Temporary** (Lost if browser cache is cleared) |
| **JSON Backup** | Your PC | **Permanent** |
| **CSV Export** | Your PC | **Permanent** |
