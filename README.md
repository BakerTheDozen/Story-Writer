# Story Writer | AI-Powered Prose Studio

An AI-powered prose studio for planning and generating stories, featuring continuity management and character tracking.

## Overview

Story Writer is a powerful, AI-driven application designed to help writers plan, organize, and generate prose. It integrates Google AI for creative assistance, manages complex story continuity with a 'Chapter Ledger,' and provides specialized tools for character and setting management. Built for speed and reliability, it offers a local-first writing experience with cross-platform support.

## Key Features

*   **AI Generation**: Generate descriptive prose using Google AI tailored to your specific goals and tone.
*   **Continuity Ledger**: Track previous chapter summaries to maintain story consistency across generated content.
*   **Character Manager**: Keep detailed records of character roles, appearances, and motivations.
*   **Local-First Storage**: Securely save your projects using IndexedDB for persistence across browser restarts.
*   **Import/Export**: Flexible backup options with support for JSON and CSV formats.
*   **Mobile Ready**: Optimized for mobile deployment using Capacitor.

## Tech Stack

*   **Frontend**: HTML5, CSS3, Vanilla JavaScript
*   **AI**: Google AI (Gemini API)
*   **Storage**: IndexedDB (local persistence)
*   **Mobile**: Capacitor (Android support)

## Getting Started

1.  Open `index.html` in a modern web browser or run `npm start` if you have Node.js installed.
2.  Set your Google AI API key in the settings (⚙️).
3.  Start writing!
