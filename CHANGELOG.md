# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-02-13
### Added
- **Google Drive Integration**: Sync projects to Google Drive for backup and restore.
- **Mobile Support**: Added Capacitor configurations for Android deployment.
- **APK Build Pipeline**: Structured build process for generating `.apk` files.
- **GitHub Documentation**: Added this changelog and updated README for better project navigation.

### Fixed
- Improved MIME type handling for JSON configuration restores.

## [1.0.0] - 2026-02-01
### Added
- **AI-Powered Prose Studio**: Core writing functionality using Google AI.
- **Continuity Managed (Chapter Ledger)**: Maintain story consistency with chapter-by-chapter summaries.
- **Character Manager**: Tools for tracking character profiles and history.
- **IndexedDB Storage**: Reliable local persistence for projects.
- **Import/Export**: Support for JSON backups and CSV exports.
